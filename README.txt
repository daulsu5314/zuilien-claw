쭈일리언 뽑기 - PWA 설치용 파일

1. 이 폴더 전체를 HTTPS 주소가 있는 웹 호스팅에 올리세요.
   - 가장 쉬운 방법: https://app.netlify.com/drop 에 폴더(또는 zip)를 끌어다 놓기
   - 또는 GitHub Pages, Cloudflare Pages, Vercel
2. 올린 주소를 휴대폰에서 열고
   - 안드로이드(크롬/삼성인터넷): 메뉴 > "앱 설치" 또는 "홈 화면에 추가"
   - 아이폰(사파리): 공유 버튼 > "홈 화면에 추가"
3. 홈 화면의 쭈일리언 뽑기 아이콘으로 실행하면 앱처럼 전체 화면으로 열리고,
   한 번 열어 두면 인터넷이 없어도 플레이할 수 있어요.

참고: 이 버전은 진행 기록(도감, 횟수)과 관리자 페이지에서 등록한 아이템이
그 기기 안에만 저장돼요.
